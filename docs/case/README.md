# E-Commerce Shop Next — Case Study

This directory contains the technical case-study documentation for the project.

## Scope

The case documents the current certified implementation of the application, including:

- application architecture;
- authentication and server session handling;
- account and commerce persistence;
- checkout and persisted orders;
- runtime and environment hardening;
- automated quality gates;
- publication evidence.

## Evidence policy

Only verified behavior should be presented as implemented.

Performance, scale, business impact, conversion, traffic, coverage percentages, and similar metrics must not be claimed without direct evidence.
