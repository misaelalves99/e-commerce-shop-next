# E-Commerce Shop Next

E-commerce moderno desenvolvido em **Next.js 15/16 + React 19 + TypeScript**, com foco em UX nível Shopee/Shein/Amazon e arquitetura pensada para portfólio profissional.

## Stack principal

- **Next.js (App Router)**
- **React 19 + TypeScript**
- **Tailwind CSS + CSS Modules**
- **Context API** para carrinho, favoritos e autenticação
- **Firebase Auth** + **Auth0** (login social)
- Arquitetura **feature-first** (`src/features/*`) + camadas `core` e `shared`

## Scripts

```bash
# desenvolvimento
npm run dev

# build de produção
npm run build

# iniciar em produção
npm start
